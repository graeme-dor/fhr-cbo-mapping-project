About this experiment

Road mode shows driving routes and kilometres from OSRM using OpenStreetMap data. It does not use live traffic. The route follows roads after snapping each location to the network; off-road access is excluded.

Rings show straight-line radius, not travel catchments. Nearest DBE scenarios are based on straight-line distance within the province and remain fixed when switching geometry.

The live map and source workbook are unchanged. Public demo routing is for occasional exploration. A dedicated provider or precomputed routes are recommended for a shared production version.
